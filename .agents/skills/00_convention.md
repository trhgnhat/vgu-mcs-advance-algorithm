# Coding Conventions for Future Agents

Read this convention after `README.md`, the Stage 00 repository rules, and the
active-stage specification. The active-stage contract takes precedence when it
sets stricter requirements.

## User Conventions

- always give examples
- Code with comments for explanation
- Coding from scratch, can use data science library in Python.
- Keep the code as simplest as possible

## Applying These Conventions

- Include a small, relevant example when explaining or delivering implemented
  behavior.
- Add concise comments for mathematical intent, assumptions, and non-obvious
  decisions. Do not comment every self-explanatory statement.
- Implement required educational algorithms from scratch. Do not substitute a
  library solver for an algorithm the project must implement.
- Use Python data-science libraries only when the active stage explicitly
  permits them and their dependency is approved and declared. Stage 1 runtime
  code remains limited to the Python standard library.
- Prefer direct functions, clear data structures, and the smallest complete
  implementation that satisfies the active contract.
